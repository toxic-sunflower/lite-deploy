lite-deploy
Как это работает Установка GitHub

Деплой на один сервер. Без Kubernetes и без панели.

lite-deploy настраивает VDS с несколькими проектами и выкатывает приложения без простоя. Один бинарник, никакого демона с правами root, открытого наружу.

$curl -fsSL https://lite-deploy.prozorov.me/install.sh | sh

Linux, amd64 или arm64. Скрипт сам поставит всё нужное для проверки подписи и возьмёт самую свежую версию.

Что внутри

Blue-green без простоя

Новая версия поднимается рядом со старой, трафик переключается после проверки здоровья. Откат одной командой.

Лёгкий стек

Podman (Quadlet), Caddy и PostgreSQL прямо на хосте. Без Docker Swarm и без кластера.

Изоляция проектов

Отдельный пользователь, роль и база на каждый проект. Ключ CI может только «выкатить» или «откатить».

Безопасная установка

Бинарник проверяется подписью minisign и SHA256. Установщик ставит один файл и больше ничего не трогает.

Как начать

  1. Поставьте lite-deploy командой выше и проверьте: lite-deploy version.
  2. Опишите проект в project.json: сервисы, порты, секреты, лимиты.
  3. Посмотрите план без изменений: lite-deploy project plan. Применяйте, когда план устраивает.

Проект развивается, первая версия закрывает команды project create, deploy, rollback и status. Подробности и решения в репозитории.
